## New features

- **Guest mode** — summoned questions in groups are answered without membership; one persistent session per chat with conversational memory, numbered/button question answers, photos, office docs, text and voice files under 10MB. Inline `@bot` mode is removed; disable Inline Mode for the bot in @BotFather.
- **Tiered access** — owner commands plus `/allow` user grants; granted users get an isolated personal chat session (prompts and answers only, no settings or commands). Guest runs never mention the GitHub token.
- **`/testmodels`** — probes free models sequentially and reports ok/failed with reasons and latency.
- **Master switch** — `/disable` / `/enable` kill-switch, `/restart` with confirmation, `/deletesessions` wipe with per-session delete.
- **`/inlinemodel`** — separate fast model for guest and lane answers; the main model is untouched.
- **Auto-compact** — optional automatic session compaction past a context threshold (`AUTO_COMPACT_THRESHOLD_PERCENT`).

## Fixes

- **Unattended permission errors** — scheduled, guest, and lane sessions start with pre-approved tool permissions, so runs no longer stall on "interactive permission cannot continue unattended".
- **Guest settings leak** — opening an auxiliary guest (`⚡ …`) or lane (`Chat …`) session no longer replaces the global default model/agent.
- **Bottom keyboard resurrection** — model/agent/variant/project switches now respect the disabled bottom keyboard in `/settings` instead of bringing the 4-button grid back.
- **Real filenames** — delivered tool outputs keep their real filenames instead of `write_*.txt`.
- **SOCKS downloads** — Telegram file downloads pick a SOCKS agent for `socks://` proxy URLs instead of forcing an HTTPS proxy agent.
